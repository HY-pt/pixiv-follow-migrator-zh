> 发布于 2026-11-20

首个版本。上游 v3.0 只有英文界面，本仓库自行完成汉化，并修掉影响实际使用的缺陷。

**新增**

- 公开 / 私密分离，关注时按每条自身标记发送
- 导入模式三选一：全部 / 公开 / 私密，支持增量覆盖
- 三种限流策略，默认暂停后自动继续
- 断点续抓：中断后从断点继续

**修复**

- 抓取只翻一页就停、深翻页停在约 96 位
- 关注节奏过于规律触发限流
- 迁移后关注顺序整体颠倒
- 触发限流后列表整个丢失
- 校验直接删人，改为校验 / 移除 / 撤销三步

**移除**

- 重复的「关闭」按钮，并入最小化

**升级**

点下方 `pixiv-follow-migrator-zh.user.js` 安装。安装前请先卸载上游旧版，两者 `@name` 不同，会并存两个面板。
