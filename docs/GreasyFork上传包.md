## 三、详细说明（Additional info，整段复制）

````markdown
## 这是什么

[Pixiv Follow Migrator v3.0](https://greasyfork.org/scripts/576458-pixiv-follow-migrator) 的中文增强版。

上游由 godlessX 以 MIT 许可发布（2026-05-03），此后未再更新。本版在保留上游版权与本声明的前提下继续维护：界面由本仓库自行汉化（上游为英文界面），并修复了实际使用中会撞到的缺陷。

> 安装前请先卸载上游旧版：本版 `@name` 与 `@namespace` 都与上游区分，会被识别为独立脚本，两者并存会出现两个面板。

## 相比上游修了什么

| 问题 | 处理 |
| --- | --- |
| 抓取只翻一页就停 | 根因是 `limit=100` 时服务端忽略 `offset`，改用 `limit=24` |
| 深翻页提前中断 | 不再把「本页不足 limit」当「已到底」；只有空页 / 整页重复 / 到达 total 才结束 |
| 关注节奏过于规律被限流 | 默认间隔 1200ms + 1~3 倍随机抖动 + 每 50 个长休眠 30 秒 |
| 迁移后关注顺序整体颠倒 | pixiv 是「最新关注排最前」，新增「关注顺序」选项，默认 reverse 还原原顺序 |
| 触发限流后列表可能整个丢失 | 只移除「确认成功 / 确认已在关注」的记录，失败与未轮到的全部保留 |
| 可重复点击执行 | 加执行锁 + 断点续抓游标 |
| 校验会直接删人且不可撤销 | 拆成三个按钮：校验关注状态（只读）/ 移除已关注记录（移除前自动备份）/ 撤销移除 |
| 私密关注抓成 0 条 | 空页区分「第一页就空」（请求失败）与「尾部空页」（已注销账号，属正常损耗） |
| 抓取总数对不上 | 说明差额来自已注销 / 被冻结账号 —— pixiv 仍计入 `total` 但接口不返回 |

## 新增能力

- 公开 / 私密分离：每条记录带自己的可见性标记，关注时按各自的标记发送
- 导入模式三选一：全部 / 公开 / 私密，增量覆盖
- 三种限流策略：暂停后自动继续（默认）/ 立即停止 / 取消关注后重新关注
- 断点续抓：中断后保留游标，再次点击从断点继续
- 逐页补漏：全量抓取漏人时可在关注列表页逐页补齐，可见性按当前标签页自动判断
- 界面：由本仓库自行汉化，不使用 emoji，面板可最小化拖动，状态栏吸顶，「高级」折叠区默认收起

## 使用要点

1. 登录 pixiv 后打开面板，点「自动抓取全部」抓当前账号的关注列表（公开 + 私密分别抓，支持断点续抓）
2. 导出 JSON 备份；换账号后导入，按「导入模式」决定并入哪张表
3. 先点「校验关注状态」确认有 N 位已在关注中，再点「移除已关注记录」
4. 点「开始自动关注」，每条按自己的公开 / 私密标记发送

## 注意

- 「取消关注后重新关注」策略会让对方收到重复关注通知，默认不启用
- 深翻页时 pixiv 对较深 offset 有限制，可能返回空页；进度会自动保留，重试可继续推进
- 已注销 / 冻结账号仍计入 total 但接口不返回，属正常损耗
````
